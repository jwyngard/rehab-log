# Rehab Log

A simple, free log for home exercise and rehab programs. Tap **+** each time you do a set; see this week vs. last week and daily charts.

**Open it:** https://jwyngard.github.io/rehab-log/

## Install on your phone
- **iPhone / iPad:** open the link in Safari → **Share** → **Add to Home Screen**.
- **Android:** open in Chrome → menu → **Install app**.
- **Desktop:** open in Chrome or Edge → install icon in the address bar.

Works offline after the first visit.

## Your data
- Stored **only on your device**. Nothing is sent anywhere; there are no accounts.
- **Edit → Export backup** saves a file you can import on another device. Do this before changing phones; deleting the app deletes its data.
- **Edit → Export spreadsheet (CSV)** to share with your PT.

## No internet / no install
Download `rehab-log.html` (Edit → Download single-file version) and open it in any browser. Data is saved in that browser.

## Files
- `index.html` – the app
- `rehab-log.html` – single-file version (generated)
- `manifest.webmanifest`, `sw.js`, `icons/` – install + offline support
- `fonts/` – Barlow, SIL Open Font License (`fonts/OFL.txt`)
