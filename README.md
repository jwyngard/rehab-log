# Rehab Log

A simple, free log for home exercise and rehab programs. Tap **+** each time you do a set; see this week vs. last week and daily charts.

**Open it:** https://jwyngard.github.io/rehab-log/

## Install on your phone
- **iPhone / iPad:** open the link in Safari → **Share** → **Add to Home Screen**.
- **Android:** open in Chrome → menu → **Install app**.
- **Desktop:** open in Chrome or Edge → install icon in the address bar.

Works offline after the first visit.

## Features
- **Day rotation (A/B or A/B/C):** Edit → Day rotation. Tag each exercise with its days, or leave it as Every day. The Log suggests the next day after the last one you did; tap A, B or C to switch, or **All** to see everything.
- **Photos and links:** Edit → an exercise → *Instructions, photos & links*. Add photos from the camera or library, or tap the paste box and Paste a photo or link. Video and web links open from the exercise's **How to** section.
- **Share an exercise list:** Edit → *Share my exercise list* exports exercises, photos and rotation (no log). Anyone can load it with **Import file**; it adds to their list without touching their log.

## Your data
- Stored **only on your device**. Nothing is sent anywhere; there are no accounts.
- **Edit → Export backup** saves a file (including photos) you can import on another device. Do this before changing phones; deleting the app deletes its data.
- **Edit → Export spreadsheet (CSV)** to share with your PT.

## No internet / no install
Download `rehab-log.html` (Edit → Download single-file version) and open it in any browser. Data is saved in that browser.

## Files
- `index.html` – the app
- `rehab-log.html` – single-file version (generated)
- `manifest.webmanifest`, `sw.js`, `icons/` – install + offline support
